# Altogether Agile — altogether-home-base

The Altogether Agile website. **Two apps, one domain:** a Next.js App Router
site in `apps/web/` (the *Site*: public, server-rendered) and a React +
TypeScript + Vite SPA in `src/` (the *App*: tools, auth, admin). `vercel.json`
rewrites decide which one answers a URL. Supabase backend (Postgres + Auth +
Edge Functions, project ref `wqaplkypnetifpqrungv`), hosted on Vercel (deploys on
push to `main`).

## Architecture

Read **[docs/PLATFORM_MIGRATION.md](docs/PLATFORM_MIGRATION.md)** before moving a
page between the two apps, adding a public route, or touching auth. Section 6a is
the current plan and the only up-to-date account of where the boundary sits.

**One owner per URL.** `src/config/siteOwnedRoutes.ts` lists the URLs the Site
answers; a test compares it against `vercel.json`, so a rewrite without a matching
entry fails the build. The App must not declare a route for a Site-owned URL and
must not reach one with `<Link>`: use `AppLink` / `useAppNavigate`, which do a real
browser navigation. Ignoring this is how the site came to have two home pages.

## Key conventions (non-obvious)

- **AI is Claude.** All AI runs in Supabase Edge Functions calling Claude Sonnet
  4.6 (`claude-sonnet-4-6`) via `supabase/functions/_shared/anthropic.ts`
  (`callClaudeJSON`). Auth-gated; secret `ANTHROPIC_API_KEY`. No JSON mode and no
  assistant-prefill — instruct JSON in the system prompt; give generous
  `max_tokens` (Sonnet truncates into invalid JSON if too low).
- **Crawler-facing SEO** depends on which app serves the page. Site pages own
  their own metadata (`generateMetadata` + `lib/seo.tsx` in `apps/web/`). For the
  pages the App still serves, it is generated by `scripts/prerender.mjs`, NOT
  React `<Helmet>`/`SEOHead`. `prerender.mjs` skips every route in its `CUT_OVER`
  list so it cannot shadow a rewrite, but it still writes the SPA shell and the
  exam OG images.
- **Canvas tools** share `src/hooks/canvas/` and `src/utils/canvas/canvasExporter.ts`.
  Tools persist into Projects as artifacts (`project_artifacts`, dispatched by
  `artifact_type` in `src/pages/ArtifactViewer.tsx`).
- **Deploy edge functions:** `npx supabase functions deploy <name> --project-ref wqaplkypnetifpqrungv`.
